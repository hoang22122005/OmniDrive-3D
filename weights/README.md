# Trọng số backbone

Gắn mã nguồn DINOv3 và checkpoint đã có quyền truy cập vào Notebook dưới dạng input riêng. Truyền đường dẫn mã nguồn cho `--dino-source` và đường dẫn checkpoint Meta tương ứng cho `--weights` ở lần train đầu. [DINOv3 của Meta](https://github.com/facebookresearch/dinov3#pretrained-models)
